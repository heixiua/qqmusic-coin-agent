# QQ音乐金币 Agent

通过 **adb + 本地 OCR** 自动刷 QQ音乐「金币狂欢节」的广告任务领金币。
当前实现是**分任务、分广告形态的确定性状态机**（坐标/文案写死在代码里），不再依赖云端 AI 看图。

> ⚠️ **免责声明（先看）**
> 本项目仅供个人学习自动化与多模态技术。
> 用脚本刷金币存在**账号被风控 / 金币清零 / 限制使用**的风险，**账号被封与作者无关**。
> 代码可以拿去用，但**不建议一直挂机刷**，请理性使用、后果自负。

## 这个项目干什么

自动在 QQ音乐 金币中心点这 4 个广告任务并串行刷完：

1. **看视频领金币**（点「看视频」→ 看广告出门 → 连续 3 次没跳广告 = 完成）
2. **看视频得高额金币**（按钮「看视频」→「领金币」→ 完成态变「明日再来」）
3. **抽奖赢金币**（点「还有6个任务,点击展开」→ 滚动半屏 → 「立即抽奖」→ 看广告抽奖 / 立即抽奖+开心收下，看广告次数用完 `0/10` = 完成）

三大任务共用**一套统一广告扫描状态机** `scan_ad_and_exit()`，所有广告出门都从这走。

## 你需要准备什么

**一台电脑**（Windows 环境已验证；Python 3.13）＋ **一台旧手机**（推荐）：

| 项 | 要求 |
|---|---|
| 手机 | **旧手机/闲置机**最好，专机专用，降低风控风险 |
| 手机安装 | **只装 QQ音乐 + 浏览器 + 应用商店**（不要装一堆 App，避免干扰和风控） |
| 开发者选项 | 开启「USB 调试」（不会就搜索"安卓USB调试怎么开"） |
| 分辨率 | **1080×2400**（模板是按这个做的，换机型要重做模板） |
| adb | 下载 https://developer.android.com/tools/releases/platform-tools ，把 `platform-tools` 文件夹放进本项目目录 |

## 从哪开始跑代码（5 步）

```powershell
cd "D:/桌面/xdf/Agent工程与具身智能/安卓手机控制"   # cwd 必须是工程根目录(相对路径模板依赖)
./platform-tools/platform-tools/adb.exe devices      # ① 确认有设备编号; 空则查USB/授权
./platform-tools/platform-tools/adb.exe shell wm size# ② 确认 1080x2400
```

**③ 手机手动进入金币中心顶部**（顶部有金币总额、任务列表「看视频领金币」那一行，无弹窗）——这是唯一手动步骤。

```powershell
python -m py_compile flow_manual.py                  # ④ 静态自检
python flow_manual.py                                # ⑤ 跑四任务串联
```

**跑完之后**：截图对照日志，确认回金币中心 + 金币增长 + 无广告残留。**只看日志不算验证**（用户经验："日志骗你"）。

> 装依赖：`pip install pillow numpy pytesseract`；还需装 Tesseract OCR 本体（https://github.com/UB-Mannheim/tesseract/wiki），中文识别。

## 广告形态与出门（碰新形态就停）

| 形态 | 怎么识别 | 怎么出门 |
|---|---|---|
| 单开门（文字门页） | 「观看广告/视频XX秒可获得奖励/积分\|退出/跳过」；「已观看XX秒」=完成态 | 轮询到已观看 → **补停3~4秒** → 点「退出」（提前1秒点会弹挽留窗弃奖） |
| 微信授权页 | 「点击允许打开微信/获取奖励」+「已观看15秒可获得积分\|退出」 | **就是单开门**，不单独分支，走上面流程 |
| 双开门·跳外部 | 点 CTA(540,2148) 后前台≠QQ音乐 | 停17~18秒 → 左滑3次 → ✕ → 放弃福利 |
| 双开门·未跳转 | 点 CTA 后仍在QQ音乐 | 停16~17秒 → 左滑1次 → ✕ → 停1秒 → 查【立即下载】→ 点【放弃福利】 |
| 激励·5秒型 | 入口文字「浏览5秒再领XX金币」 | 点弹窗 → 跳外部 → 停5.5~6秒 左滑3次 |
| 激励·15秒型 | 入口文字「浏览广告+XX金币」 | 可能是单开门(点退出)/双开门(点CTA)，按检测分流 |
| 红包雨（非广告） | 点看视频后进「红包雨来啦」动画 | 非广告，任务层判完成 |

> ⚠️ 广告形态会被平台**不断更换**。脚本靠 OCR 读入口文字区分，**遇到没见过的形态会停住等人工**，不要让它自动硬闯。

## 哪里需要改进（当前已知缺陷）

| 优先级 | 问题 | 说明 |
|---|---|---|
| **D1** | 高额金币出门后定位脆弱 | 出门后滚动位置不稳定 + 标题行 OCR 偶发失败 → 会停住。建议：标题行锁定失败时兜底全屏扫右侧按钮文字「领金币/看视频/明日再来」直接定位 |
| **D2** | 抽奖阶段左滑收尾偶发落「我的」页 | 左滑后可能落到底部导航「我的」页，需修落点/改用导航切换 |
| D3 | 依赖相对路径 cwd | 换目录跑会崩；建议文件头加 `os.chdir(os.path.dirname(os.path.abspath(__file__)))` |
| D4 | 新机型要重做模板 | 换分辨率/界面版本后 `tpl_*.png` 失效，需按新截图重做 |

**项目纪律（务必遵守）**：碰新广告形态先停住固定现场再改代码；一次只改一件事；每个「能跑通」节点提交一次 git；跑完清理临时截图/日志；提交不带垃圾文件。
